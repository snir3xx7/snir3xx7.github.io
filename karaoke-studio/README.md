# קריוקי סטודיו – הוראות

אתר קריוקי חינמי בעברית. בלי חשבון, בלי שרת, בלי מפתחות API. כל הקבצים וההקלטות נשמרים בדפדפן במכשיר שלכם.

## מה עובד כרגע (שלב 1, נבדק)

- ספרייה עם חיפוש בעברית ובאנגלית, סינון לפי שפה ומועדפים.
- שיר הדגמה מקורי ("לילה בעיר") עם 4 ערוצים (תופים, בס, קלידים, קול מנחה) ומילים מתוזמנות לכל מילה.
- מסך שירה: שורה נוכחית גדולה, שורה הבאה, הדגשת מילים, ספירה לאחור, דילוג ±5 שניות, הפסקה מוזיקלית עם ספירה.
- הקלטה מעל הפלייבק, מד עוצמה, שמירת כל טייק בנפרד (גם אם האפליקציה עוברת לרקע באמצע).
- אולפן: עוצמה/השתקה/סולו לכל ערוץ, "השתק שירה", האזנה למקור, היסט טייק במילישניות, חיתוך שקט, EQ, הגדרות "קול נקי" / "קול חם" / "אולם" (קומפרסור + ריוורב), לימיטר ראשי, השוואה עם/בלי אפקטים.
- ייבוא פלייבק משלכם (MP3 / WAV, ו-M4A אם הדפדפן מפענח) וייבוא הקלטת שירה קיימת.
- עורך מילים: הדבקה, תזמון ידני בלחיצה או ברווח, כיוון ±0.05 שנ׳, פיצול/איחוד/מחיקה, הזזת כל המילים, ייבוא וייצוא LRC/SRT.
- ייצוא WAV 24 ביט: מיקס סופי, פלייבק בלבד, טייק בלבד (עם או בלי אפקטים).
- שמירה אוטומטית במכשיר, וייצוא/ייבוא קובץ פרויקט (zip) להעברה בין מחשב לטלפון.

## עוד לא קיים (בכוונה לא מוצג באתר)

- הפרדת ערוצים משיר מלא (שלב 3 – רכיב מקומי למק).
- קטלוג חיצוני והטמעות YouTube וכו' (שלב 2).
- תזמון אוטומטי, הפחתת רעשים ותיקון זיופים (שלב 4).
- ייצוא MP3 וייצוא וידאו.

## הפעלה במחשב (מק)

1. פתחו את Terminal (Cmd+רווח, כתבו Terminal, Enter).
2. הדביקו (החליפו את הנתיב למקום שבו פתחתם את התיקייה):

```
cd ~/Downloads/karaoke-studio
python3 -m http.server 8080
```

3. פתחו בדפדפן: http://localhost:8080
4. כדי לעצור: חזרו ל-Terminal ולחצו Ctrl+C.

הקלטה עובדת רק בכתובת מאובטחת (https) או ב-localhost. פתיחה של index.html בלחיצה כפולה לא תעבוד.

## פריסה חינמית ב-GitHub Pages

מסלול: GitHub Pages מאחסן אתרים סטטיים בחינם, ב-https (כך שהמיקרופון עובד גם בטלפון). מגבלות עיקריות: המאגר והאתר ציבוריים, נפח אתר עד כ-1GB, ותעבורה מומלצת עד כ-100GB בחודש.

1. היכנסו ל-github.com למאגר `snir3xx7.github.io`.
2. לחצו **Add file** ← **Upload files**.
3. גררו לחלון את **התיקייה** `karaoke-studio` כולה (התיקייה עצמה, לא רק את הקבצים שבתוכה).
4. למטה לחצו **Commit changes**.
5. אחרי דקה-שתיים האתר יהיה בכתובת: https://snir3xx7.github.io/karaoke-studio/

## הקלטה ראשונה

1. ספריית קריוקי ← "לילה בעיר" ← **לשיר**.
2. שימו אוזניות. לחצו על הכפתור הוורוד. אשרו גישה למיקרופון.
3. אחרי הספירה לאחור – שירו. לחצו שוב על הכפתור הוורוד כדי לעצור.
4. **לאולפן ›** ← כוונו עוצמה והיסט, בחרו אפקט.
5. **ייצוא ושמירה** ← **מיקס סופי**.

## מעבר מהמחשב לטלפון

1. במחשב: אולפן ← ייצוא ושמירה ← **ייצוא קובץ פרויקט**.
2. העבירו את הקובץ לטלפון (AirDrop, וואטסאפ לעצמכם, Google Drive).
3. בטלפון: פתחו את האתר ← ספריית קריוקי ← **פתיחת קובץ פרויקט (.zip)** ← בחרו את הקובץ.

## מבנה

- `index.html`, `css/`, `js/` – האתר עצמו, בלי שלב בנייה.
- `js/engine.js` – ניגון מסונכרן, הקלטה וייצוא (אותו מנוע לתצוגה מקדימה ולייצוא).
- `catalog.json` – הקטלוג. כל פריט: `title`, `artist`, `lang`, `type`, `source`, `license`, `url`.
- `demo/` – שיר ההדגמה (מקורי, נוצר ע"י `tools/make_demo.py`).
